# Style References

This folder holds reusable style notes, palette strips and selection guidance. It
is not a replacement for `config/art_styles.yaml`; the registry defines style
families, while these files explain how to choose and apply one.

## Contents

- `style_selector.md` — decision matrix for choosing a style family.
- `palette_mosslight.md` — the example project's palette with roles and usage.

## Rules

- A project copies the chosen style into its own frozen `style_guide.yaml`.
- Do not edit a shared registry to make a project-only decision.
- Do not name a living artist or request imitation of a protected character.
- Record palette exceptions and get them reviewed.
