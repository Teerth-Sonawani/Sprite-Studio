# Worked Examples

These examples show how the templates are actually filled in. They are
reference material, not extra templates: copy values only when they fit the
project, and record any deviation.

| File | Demonstrates |
|---|---|
| `moss_light_art_direction.md` | Turning a mood sentence into a frozen, testable art direction |
| `asset_brief_walkthrough.md` | Converting a vague request into a validated brief and prompt |

The worked project that applies both is
[`projects/example-project`](../../projects/example-project/README.md). Its
assets are original procedural demo art, not AI-generated artwork.

## What makes a useful example

- It names concrete decisions (canvas, pivot, palette, outline, lighting)
  instead of adjectives alone.
- It shows the rejection criteria, not only the aspiration.
- It distinguishes what was done from what remains unproven.
- It never claims human approval that did not happen.
